1️⃣  INSTALLATION INITIALE
═══════════════════════════════════════════════════════════════════════════════

Sur Windows:
    1. Double-cliquez sur: install.bat
    OU via terminal (cmd ou PowerShell):
        install.bat

Sur Linux/Mac:
    1. Ouvrez un terminal
    2. cd medical-booking-laravel
    3. bash install.sh

Le script d'installation va:
    ✓ Installer les dépendances PHP (Composer)
    ✓ Configurer le fichier .env
    ✓ Générer la clé d'application
    ✓ Exécuter les migrations
    ✓ Remplir la base de données avec des données de test
    ✓ Installer les dépendances JavaScript (npm)
    ✓ Compiler les assets (CSS, JS)

═══════════════════════════════════════════════════════════════════════════════
2️⃣  LANCEMENT DU SERVEUR
═══════════════════════════════════════════════════════════════════════════════

Ouvrez un terminal dans le répertoire du projet et exécutez:

    php artisan serve

Le serveur démarre sur: http://localhost:8000

6️⃣  COMMANDES ARTISAN UTILES
═══════════════════════════════════════════════════════════════════════════════

Réinitialiser la base de données:
    php artisan migrate:fresh --seed

Vider le cache:
    php artisan cache:clear

Consulter la base de données avec Tinker:
    php artisan tinker

Générer une migration:
    php artisan make:migration create_table_name

Générer un modèle:
    php artisan make:model ModelName

Générer un contrôleur:
    php artisan make:controller ControllerName

7️⃣  DÉPANNAGE
═══════════════════════════════════════════════════════════════════════════════

❌ Erreur "File not found" pour les images:
    ✓ Exécutez: php artisan storage:link

❌ Erreur "SQLSTATE[HY000]":
    ✓ Vérifiez que MySQL est lancé
    ✓ Vérifiez les credentials dans .env
    ✓ Exécutez: php artisan migrate

❌ Erreur "Class not found":
    ✓ Exécutez: composer dump-autoload

❌ Problème de permission:
    ✓ Windows: Aucune action nécessaire
    ✓ Linux: chmod -R 775 storage bootstrap/cache
