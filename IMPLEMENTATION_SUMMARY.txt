🔧 CONFIGURATION & DÉPLOIEMENT
═══════════════════════════════════════════════════════════════════════════════

Avant le lancement:

1. Dupliquer .env.example en .env
2. Configurer les variables d'environnement:
   - APP_KEY: Générer avec "php artisan key:generate"
   - DB_DATABASE: medical_booking (ou autre)
   - DB_USERNAME: root (ou autre)
   - DB_PASSWORD: (votre mot de passe MySQL)

3. Exécuter les migrations:
   php artisan migrate

4. Remplir la base de données:
   php artisan db:seed

5. Lier le stockage:
   php artisan storage:link

6. Compiler les assets:
   npm run build (production) ou npm run dev (développement)

7. Lancer le serveur:
   php artisan serve
