⚠️  POINTS IMPORTANTS À VÉRIFIER
═══════════════════════════════════════════════════════════════════════════════

1. BASE DE DONNÉES:
   ✓ MySQL doit être installé et lancé
   ✓ La base de données 'medical_booking' sera créée automatiquement
   ✓ Les tables seront créées par les migrations

2. FICHIER .ENV:
   ✓ Dupliquer .env.example → .env
   ✓ Générer la clé: php artisan key:generate
   ✓ Configurer: DB_HOST, DB_USERNAME, DB_PASSWORD

3. DÉPENDANCES:
   ✓ PHP 8.3+
   ✓ Composer (pour les dépendances PHP)
   ✓ Node.js & npm (pour les assets frontend)

4. PERMISSIONS (Linux/Mac):
   ✓ storage/ doit être writable
   ✓ bootstrap/cache/ doit être writable
   
   Commandes:
   chmod -R 775 storage
   chmod -R 775 bootstrap/cache

🔧 CONFIGURATION DÉTAILLÉE
═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: Préparation
─────────────────────

1. Ouvrir un terminal dans le répertoire du projet
2. Copier le fichier .env:
   Windows: copy .env.example .env
   Linux/Mac: cp .env.example .env

ÉTAPE 2: Installation
──────────────────────

Option A - Script automatique (RECOMMANDÉ):
   Windows: install.bat
   Linux/Mac: bash install.sh

Option B - Manuelle:
   1. composer install
   2. php artisan key:generate
   3. php artisan migrate
   4. php artisan db:seed
   5. php artisan storage:link
   6. npm install
   7. npm run build

ÉTAPE 3: Lancement
───────────────────

Terminal 1 (Serveur PHP):
   php artisan serve
   → L'application est accessible sur http://localhost:8000

Terminal 2 (Watch assets - optionnel):
   npm run dev
   → Pour développement avec hot reload

ÉTAPE 4: Premier accès
───────────────────────

Aller à: http://localhost:8000

Comptes de test:
   Admin:   admin@gmail.com / password
   Patient: patient@[random].com / password
   Doctor:  doctor@[random].com / password

🐛 DÉPANNAGE COURANT
═══════════════════════════════════════════════════════════════════════════════

Erreur: "SQLSTATE[HY000]: General error: 1030 Got error..."
Cause: MySQL n'est pas lancé ou credentials incorrect
Solution:
  1. Vérifier que MySQL est lancé
  2. Vérifier DB_HOST, DB_USERNAME, DB_PASSWORD dans .env
  3. Vérifier que la base de données existe ou créer:
     CREATE DATABASE medical_booking;

Erreur: "Class not found"
Cause: Autoloader pas à jour
Solution:
  composer dump-autoload

Erreur: "File not found" pour les images
Cause: Symlink du storage pas créé
Solution:
  php artisan storage:link

Erreur: "No such file or directory" pour npm
Cause: Node.js/npm pas installé
Solution:
  1. Installer Node.js depuis https://nodejs.org
  2. Relancer le terminal
  3. npm install

Erreur: "Permission denied"
Cause: Permissions insuffisantes sur storage/bootstrap
Solution (Linux/Mac):
  chmod -R 775 storage bootstrap/cache

Erreur: "The APP_KEY is not set"
Cause: APP_KEY pas générée
Solution:
  php artisan key:generate
