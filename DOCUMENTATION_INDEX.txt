⚡ COMMANDES ESSENTIELLES
═══════════════════════════════════════════════════════════════════════════════

INSTALLATION:
  composer install              # Installer les dépendances PHP
  npm install                   # Installer les dépendances JS
  php artisan key:generate      # Générer APP_KEY

DÉVELOPPEMENT:
  php artisan serve             # Lancer le serveur
  npm run dev                   # Watch assets
  npm run build                 # Compiler les assets

BASE DE DONNÉES:
  php artisan migrate           # Exécuter les migrations
  php artisan migrate:fresh     # Réinitialiser la BD
  php artisan db:seed           # Remplir avec des données
  php artisan tinker            # REPL interactive

UTILITAIRE:
  php artisan cache:clear       # Vider le cache
  composer dump-autoload        # Recharger l'autoloader
  php artisan storage:link      # Lier le stockage public

🚨 ERREURS COURANTES
═══════════════════════════════════════════════════════════════════════════════

Erreur: "Class not found"
  → Exécuter: composer dump-autoload

Erreur: "SQLSTATE[HY000]"
  → MySQL n'est pas lancé ou identifiants incorrects

Erreur: "File not found" pour les images
  → Exécuter: php artisan storage:link

Erreur: "Module not found" pour npm
  → Exécuter: npm install
