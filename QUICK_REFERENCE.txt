📋 COMMANDES ESSENTIELLES
═══════════════════════════════════════════════════════════════════════════════

INSTALLATION:
  composer install              # Installer les dépendances PHP
  npm install                   # Installer les dépendances JS
  php artisan key:generate      # Générer APP_KEY

BASE DE DONNÉES:
  php artisan migrate           # Exécuter les migrations
  php artisan migrate:fresh     # Réinitialiser (DANGER!)
  php artisan db:seed           # Remplir avec données de test
  php artisan tinker            # Console interactive

SERVEUR:
  php artisan serve             # Lancer le serveur
  npm run dev                   # Watch assets (dev)
  npm run build                 # Compiler assets (prod)

CACHE:
  php artisan cache:clear       # Vider le cache
  php artisan config:cache      # Cache la config
  composer dump-autoload        # Recharger autoloader

STOCKAGE:
  php artisan storage:link      # Lier le storage public

🐛 DÉPANNAGE RAPIDE
═══════════════════════════════════════════════════════════════════════════════

PROBLÈME: "Class not found"
  SOLUTION: composer dump-autoload

PROBLÈME: "Database connection failed"
  SOLUTION: Vérifier MySQL, configurer .env (DB_HOST, DB_USERNAME, DB_PASSWORD)

PROBLÈME: "File not found" pour images
  SOLUTION: php artisan storage:link

PROBLÈME: "No such file or directory" npm
  SOLUTION: Installer Node.js depuis nodejs.org

PROBLÈME: "Undefined variable in view"
  SOLUTION: Vérifier que le controller passe la variable à la vue

PROBLÈME: "403 Unauthorized"
  SOLUTION: Vérifier les middleware et policies

PROBLÈME: "404 Not Found"
  SOLUTION: Vérifier la route dans routes/web.php

═══════════════════════════════════════════════════════════════════════════════
🎯 CAS D'USAGE COURANTS
═══════════════════════════════════════════════════════════════════════════════

AJOUTER UN NOUVEAU CHAMP:
  1. Créer migration: php artisan make:migration
  2. Éditer la migration (ajouter la colonne)
  3. Éditer le Model (si besoin fillable/casts)
  4. Éditer Form Request (validation)
  5. Éditer la vue Blade
  6. Éditer le Controller

CRÉER UNE NOUVELLE PAGE:
  1. Ajouter la route dans routes/web.php
  2. Créer le contrôleur: php artisan make:controller
  3. Créer la vue: resources/views/[nom].blade.php
  4. Implémenter la logique dans le contrôleur

AJOUTER UNE VALIDATION:
  1. Créer Form Request: php artisan make:request
  2. Ajouter les règles dans rules()
  3. Ajouter autorisation dans authorize()
  4. Utiliser dans le contrôleur: public function store(FormRequest $request)
